ایجاد پشتیبان از پایگاه داده

با استفاده از این بخش می‌توانید از تمام داده‌های پایگاه داده یک فایل پشتیبان (SQL dump) ایجاد کنید. این فایل شامل تمام جداول، داده‌ها و ساختار پایگاه داده است.

  • شامل تمام جداول و داده‌ها
  • فرمت SQL استاندارد
  • قابل استفاده در هر سیستم PostgreSQL
فایل پشتیبان با نام soldier_db_backup_YYYYMMDD_HHMMSS.sql دانلود می‌شود.

بازگردانی پشتیبان به پایگاه داده

با استفاده از این بخش می‌توانید یک فایل پشتیبان قبلی را به پایگاه داده بازگردانی کنید. توجه: این عمل تمام داده‌های فعلی را حذف و با داده‌های فایل پشتیبان جایگزین می‌کند.

هشدار: این عملیات غیرقابل بازگشت است! قبل از ادامه، حتماً از داده‌های فعلی پشتیبان تهیه کنید.

راهنمای استفاده
ایجاد پشتیبان:
  1. روی دکمه "دانلود پشتیبان پایگاه داده" کلیک کنید
  2. فایل SQL دانلود شده را در محل امنی ذخیره کنید
  3. برای امنیت بیشتر، فایل را در چند مکان مختلف نگهداری کنید
  4. به صورت منظم (مثلاً هفتگی یا ماهانه) پشتیبان تهیه کنید
بازگردانی پشتیبان:
  1. قبل از بازگردانی، حتماً از داده‌های فعلی پشتیبان تهیه کنید
  2. فایل پشتیبان قبلی (.sql) را انتخاب کنید
  3. روی دکمه "بازگردانی پشتیبان" کلیک کنید
  4. در پیام تأیید، "OK" را انتخاب کنید
  5. پس از اتمام، صفحه را رفرش کنید
نکته: برای استفاده از این قابلیت، ابزارهای PostgreSQL client (pg_dump و psql) باید در سیستم نصب باشند. در محیط Docker، این ابزارها معمولاً به صورت پیش‌فرض موجود هستند.
